# 不胖为什么会有小肚子？当心这两种妇科病

> 更新时间：2026-09-11 (UTC+8)

长沙百佳玛丽亚妇产医院妇科团队正在为患者行子宫肌瘤剔除术。

很多女性感觉很奇怪，明明体重都在正常范围，可就是有点小肚子！甚至还有点硬硬的，鼓鼓的，就算再怎么减肥，“小腹婆”都不离不弃。这到底是为什么？其实，腹部赘肉可能是很多原因造成的，但是如果肚子总是硬硬的、圆鼓鼓的，就要当心子宫肌瘤跟卵巢囊肿这两种妇科病找上门。

**一、子宫肌瘤是什么？**

子宫肌瘤是女性常见的盆腔良性肿瘤。在育龄期女性中，发病率可达25%，而围绝经初期女性中，发病率达到70%。患者常表现为月经过多，盆腔疼痛，育龄期女性多伴发盆腔压迫、尿频、便秘、腹胀、性交痛以及腹部包块。

**二、子宫肌瘤有哪些症状？**

1. 月经过多或者月经周期延长，有10%的患者会出现月经期间出血。这是由于肌瘤可能会导致宫腔增大，子宫内膜面积增加并影响子宫收缩，如果肌瘤压迫静脉血管，可引起经量增多、经期延长。长期经量增多可能还会引起继发性贫血。

2. 严重痛经。约有60%的子宫肌瘤患者有痛经的症状。子宫黏膜下肌瘤发生中、重度痛经的患者是无子宫肌瘤患者的3倍。有研究数据显示，在那些因月经过多或有腹痛等症状而就诊的患者中，40岁以上女性子宫肌瘤的患病率高达40%。

3. 小腹坠胀。随着子宫肌瘤逐渐增大，患者会感觉到小腹位置肿大或有坠胀感。如果子宫肌瘤继续变大，压迫到其他器官组织，还会带来更多不适症状，例如子宫肌瘤位于子宫底部可引起性交不适和无规律的疼痛，前壁肌瘤可引起膀胱功能失调，甚至引起输尿管完全阻塞，后壁肌瘤可引起直肠压迫症状，甚至导致大肠梗阻。

**三、卵巢囊肿是什么？**

卵巢囊肿是一种在育龄女性中常见于的疾病，分成两种：一种是生理性的，跟月经周期有关系。只是在超声检查里看着像囊肿，会在几个周期内自行消失。另一种是病理性的，大部分情况下是良性的肿瘤。只有很小一部分卵巢囊肿是恶性肿瘤，多见于绝经后新出现的卵巢囊肿。

**四、卵巢囊肿有哪些症状？**

1. 腰围变粗、腹内肿物。不少患有卵巢囊肿的患者都会感觉到自己的腰围变粗，在日常穿衣过程中会有明显的感受，比如衣物或者腰带变小变紧。患者在晨起过程中按压腹部还会感受到肿物等的存在，伴有腹胀不适感。

2. 腹痛症状。腹痛也是卵巢肿瘤患者的常见症状。出现该症状的主要原因在于瘤蒂发生扭转现象，或者囊肿发生破裂、出血以及感染现象，导致患者疼痛难忍。此外，恶性囊肿在很大概率上会引起腿痛、腹痛症状。

3. 月经不调。如果患者存在单侧、双侧卵巢囊肿症状，一般不会对正常卵巢组织带来影响，但是却会导致患者出现月经紊乱现象。多数月经失调的患者伴有卵泡囊肿等病症。

4. 痛经。因为卵巢囊肿极易对正常的卵巢细胞造成破坏，因此可能会导致女性患者在月经期间出现痛经现象，如果已经确诊的患者发生了持续性的痛经，那么需要考虑卵巢囊肿症状是否已经加重。

5. 不孕症状。不少患者刚开始并不知道自己患有卵巢囊肿病症，但是就是无法正常怀孕，在不孕检查过程中才发现卵巢存在囊肿组织，进而影响了机体的正常排卵，直接影响女性的生育能力。

**五、这两种妇科病容易“盯上”哪些人？**

女性朋友如果在饭量没有增加、运动量没变化、排除怀孕的情况下，身体其他部分没变胖唯独小肚子鼓出来，触摸起来感觉比肉稍硬结实，要小心子宫肌瘤或卵巢肿瘤。特别是月经发生了改变，经量增多，经期延长，经期不规律以及尿频的女性朋友，更要当心。此外，停经后小肚子显著变大也不能大意。

**六、如何预防这两种妇科病？**

1. 良好生活习惯：注意饮食均衡，多食高蛋白跟清淡的食物，少吃咸辣食物，还应戒烟戒酒。

2. 注重心理调节：保持良好的情绪，适当缓解压力，工作跟生活中要劳逸结合，避免劳累。

3. 加强体育锻炼：多进行户外运动，例如跑步、瑜伽、跳绳等，多喝水，多排汗，增强体质。

4. 坚持定期检查：定期检查的目的是为了做到早发现、早诊断、早治疗。一旦发现自己有这方面的症状，应尽早就医，防止病情恶化，耽误最佳治疗时机，造成不可弥补的伤害。(通讯员 黄颖)
